# Komorebi Monitor

> Komorebi tool for displaying the active workspace in the Taskbar plus additional toggles.

## Installation

1. Download the latest release from the [Releases page](https://github.com/microBob/KomorebiMonitor/releases/latest).
2. Add `-t 3003` to the end of the Komorebi startup command found in the shortcut at `shell:startup\komorebi.lnk`
3. Add the `komorebi-monitor.exe` to your startup folder at `shell:startup\`.
